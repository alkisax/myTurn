# MyTurn

MyTurn is a digital queue-management application for businesses and organizations. It replaces traditional paper queue tickets with digital tickets, helping customers wait more conveniently and helping staff manage service queues clearly.

## What can MyTurn do?

Customers can:

- Get a queue number remotely or from an on-site kiosk/tablet.
- Track their ticket and estimated waiting time.
- Receive ticket information through QR codes, PDF tickets, and email where available.
- See which number is currently being served.

Staff can work from assigned desks and queues, call the next customer, complete, miss, or recall tickets, use break and session functionality, and update public number displays in realtime.

Administrators can manage organizations, locations, queues, services, desks, staff, and analytics.

## How it works

Customer gets a ticket -> waits remotely -> staff calls the next customer -> the public display updates in realtime.
